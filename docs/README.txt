# Estufa IoT com Arduino
Circuito com TMP36, LED, buzzer e motor (exaustor). Ventila a 30 °C e gera alerta (LED+buzzer) a ≥ 50 °C.

## Componentes
Arduino UNO, TMP36, LED + resistor 220Ω, buzzer, motor DC + 2N2222 + diodo 1N4007 + resistor 1kΩ, protoboard, jumpers.
